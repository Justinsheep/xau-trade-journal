# XAU 交易紀錄

即時追蹤 OKX `XAU-USDT-SWAP`，依「每單虧損 = 帳戶最高點 × 10%」規則計算倉位，並自動判斷止盈 / 止損結單。

- 即時價格：OKX 公開 WebSocket（斷線自動改用 REST）
- 下單：輸入進場、止損，再輸入止盈或 RR（兩者互相換算），顯示名義價值、XAU 數量、OKX 張數（1 張 = 0.001 XAU）
- 結單：網頁開著時用即時價格判斷；網頁關著的期間，下次打開時用 OKX 1 分 K 回補判斷（同一根 K 同時碰到止盈止損時保守判定止損）
- 統計：總營利、勝率、平均 RR、帳戶最高點、回撤、權益曲線
- 資料存在瀏覽器 localStorage，可匯出 / 匯入 JSON

純靜態網頁，GitHub Pages 直接部署，無需 build。
